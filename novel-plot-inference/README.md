# Novel Plot Inference

一个面向**既有小说项目**的剧情推演与设计 Skill。

它不是自动续写器，也不是单纯的设定文档管理器。它以项目自己的权威设定和人物状态为边界，从人物目标、认知、选择与行动出发，推演剧情路径、因果后果、场景冲突、悬念和揭示顺序。

## 核心能力

- 从人物目标、知识、误解、资源和限制推演行动；
- 把“当前状态 → 判断 → 选择 → 行动 → 反应 → 后果”连成可检查的因果链；
- 设计不同的剧情分支，并比较各自的戏剧效果和设定风险；
- 设计场景冲突、转折、信息差、线索与揭示顺序；
- 检查人物知识边界、时间线、规则约束和伏笔连续性；
- 将已确认、未决、推断、已废弃严格分开；
- 遵守作者确认流程，不把候选剧情擅自升级为定稿。

## 设计原则

**剧情由人物目标和行动推动，世界观机制负责约束和影响行动，不负责替人物安排剧情。**

项目资料缺失时，Skill 应说明缺口及其影响；不得为了给出完整方案而补造机制、身份、关系、动机或结局。

## 安装

将 `novel-plot-inference/` 目录放入 Agent 支持的 Skill 发现路径。具体路径和调用方式取决于 Agent 平台。

## 使用示例

- 根据某人物当前知道的信息，推演他接下来可能采取的行动。
- 设计一场人物目标冲突明确、且符合现有设定的场景。
- 为某个剧情节点提出多条因果成立的后续路径。
- 比较两种揭示顺序对人物认知和读者悬念的影响。
- 检查一段剧情是否依赖角色尚未获得的信息。
- 找出剧情推进中缺失的因果环节，但不要替作者补设定。
- 根据已确认的卷纲推演章纲候选，不擅自决定卷边界或结局。
