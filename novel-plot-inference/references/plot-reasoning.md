# Plot Reasoning

## Purpose

Turn a story question into a traceable reasoning problem. The goal is not to guess the author's intended plot, but to discover which developments follow from established character states and story conditions.

## 1. Define the question

Restate the exact decision or gap being explored. Identify:
- the focal character or event;
- the point in story time;
- the desired scale (action, scene, sequence, volume, mainline);
- what the author wants to preserve;
- what must not be decided yet.

Do not answer a broader question than the author asked.

## 2. Establish the starting state

Use only relevant confirmed information:
- current goals and immediate needs;
- available knowledge and beliefs;
- emotional or relational context explicitly established;
- resources, permissions, abilities, and constraints;
- other actors' known goals and likely responses;
- current external conditions;
- unresolved facts that affect feasibility.

Mark missing inputs as unknown. Do not silently assume a default.

## 3. Generate actions before events

Ask what the character could deliberately do, not what dramatic event could conveniently happen to them.

For each action candidate, identify:
- intended result;
- reason the character would choose it now;
- information and resources required;
- obstacle or uncertainty;
- likely response from affected people;
- cost or consequence only when supported by the project;
- what new state the action creates.

An event without a character choice can still occur, but its source and causal role must be clear.

## 4. Build a causal graph

Represent the chain as:

`State_0 → Judgment → Choice → Action → Response → Outcome → State_1`

For branches, identify the earliest point where paths diverge. Do not create branches that differ only in wording. They should differ in a meaningful choice, response, information state, or consequence.

## 5. Test each link

For every arrow, ask:
- What evidence supports this transition?
- Is the actor capable of doing this at this time?
- Does the actor know enough to choose it?
- Is the response attributable to a known person, institution, environment, or rule?
- Does the outcome actually follow?
- Does the outcome preserve all established constraints?

Classify a missing link as:
- missing motivation;
- missing information;
- missing capability;
- missing trigger;
- unsupported response;
- unexplained outcome;
- unresolved rule interaction.

These labels diagnose the gap; they do not authorize adding the missing element.

## 6. Compare candidate paths

Compare paths by:
- character agency;
- causal clarity;
- consistency with established facts;
- meaningful change in the character's situation;
- new choices created or removed;
- information revealed or withheld;
- dependencies on unresolved decisions;
- downstream continuity cost.

Do not rank a path as best merely because it is more dramatic. Explain the trade-off.

## 7. Distinguish deduction from invention

- **Deduction**: a consequence that follows from confirmed premises.
- **Plausible option**: one possible action or outcome among several.
- **New proposal**: an event, motive, character action, or rule not yet established.
- **Unsupported leap**: a result for which the chain lacks a necessary premise.

Use the correct label. If a new premise is needed, state it explicitly and ask whether the author wants to consider it.

## 8. Output

Prefer compact, traceable reasoning:
- starting facts;
- causal chain;
- branch point;
- candidate outcomes;
- assumptions required;
- unresolved decisions.

Never disguise a proposal as a deduction.
