# Canon Boundaries for Plot Inference

## Purpose

Keep established story facts separate from possible plot developments.

## 1. Four status categories

Use the project's status language where available. Otherwise:

| Status | Meaning | How to use it |
|---|---|---|
| **Confirmed** | Explicitly established by the author or valid project source | May constrain plot design |
| **Unresolved** | Not decided, incomplete, or not resolved by source authority | Keep open; identify its impact |
| **Inferred** | Reasoned interpretation or possible development | May be explored as a proposal, never treated as canon |
| **Deprecated** | Explicitly withdrawn or superseded | Exclude from current reasoning except to explain history |

## 2. Classify plot statements

For every important statement in a proposal, distinguish:
- **Premise**: confirmed fact used as the starting point;
- **Deduction**: consequence that follows from confirmed premises;
- **Option**: one plausible path among several;
- **New proposal**: introduces a new action, event, motive, clue, or rule;
- **Open question**: requires author decision.

A deduction is only as reliable as its premises. If a premise is unresolved, the conclusion cannot be presented as confirmed.

## 3. Handle missing information

A missing fact is not automatically false and not automatically true. State:
- what is not established;
- why the missing fact matters;
- which parts of the plot can still be explored without it;
- what decision, if any, the author needs to make.

Do not create a placeholder fact and then reason from it as if it were true.

## 4. Handle conflicts

When sources conflict:
1. inspect the project's authority rules;
2. compare scope, time, and perspective;
3. apply an explicit project rule if it resolves the issue;
4. otherwise keep the point unresolved.

Do not choose whichever version makes the plot easier.

## 5. Deprecated content

A deprecated rule, name, relationship, or plot direction must not re-enter a proposal as a hidden premise. If a former version is relevant, label it historical and explain that it is not current canon.

## 6. Evidence notes

For major premises, cite the file and heading or exact location. If a source could not be accessed, say so. Never fabricate a source or claim.
